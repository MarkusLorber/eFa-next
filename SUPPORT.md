# Support

## Community

- Documentation: `docs/README.md`, the first steps in `docs/first-steps.md`, answers in `docs/faq.md`.
- Questions and bug reports: the issue tracker of the repository you got eFa-next from.
  Please give the version (`efactl status`), what you did and what happened, and leave out passwords, keys and real mail.
- Security problems: never in a public issue, see `SECURITY.md`.

Community help is given by volunteers, without guaranteed times.

eFa-next is free software without paid support offers. IT-World ITW GmbH sponsors the project (domain and mail service) and
uses eFa-next itself; it sells neither eFa-next nor support for it.
